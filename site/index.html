How it works

Compare configuration with readback

  1. Declare settingsPoint to the Supabase configuration you applied.
  2. Read provider stateUse a live read-only request or a saved JSON response.
  3. Keep the receiptUse exit code 2 when a field changed or cannot be checked.

Privacy and limits

What Apply Witness does not do

It does not apply configuration. It does not store provider tokens. It never treats an omitted field as applied.

Secret-like fields and environment substitutions are redacted from receipts. The free command works one project at a time.
