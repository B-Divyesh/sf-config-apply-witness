How Apply Witness handles data

Apply Witness checks configuration on your machine. It has no telemetry or behavioral analytics.

Configuration and provider access

The CLI reads the configuration file you select. Live verification sends one read-only request to Supabase’s Management API.

Provider access tokens stay in your environment. The CLI does not store or print them. Offline fixture mode sends no provider request.

Receipts and redaction

A receipt contains the configuration hash, timing, provider identity, results, and redacted field values. Paths and values that look like secrets, including environment substitutions, are redacted.

Receipt files use owner-only permissions on supported Unix systems. You choose where to save a receipt.

License data

The website stores a license token and its latest verdict in browser local storage only after you supply a token. The CLI stores a license token and verdict in its user cache with owner-only permissions.

License verification sends the token to Sociobot at api.sociobot.in. A valid cached verdict is reused for up to one day.

Payments and choices

Sociobot / Dodo hosts checkout and processes payment details. This site does not receive card details.

Clear this site’s local storage to remove a browser license. Remove apply-witness/license.json from your user cache to remove the CLI license. Send privacy questions to privacy@sociobot.in.
