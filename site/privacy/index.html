Policy · effective 28 August 2026

Privacy

Apply Witness is designed to collect as little as possible. The CLI has no analytics or telemetry, and configuration processing happens on your machine.

CLI data

The CLI reads the configuration file you select and, for live verification, sends a read-only request directly to Supabase’s Management API. Provider access tokens stay in your environment and are not written to receipts. Secret-like fields are redacted. Offline fixture mode makes no provider request.

License data

If you buy or restore the Team Receipt Kit, this website stores the license token and its latest verification verdict in your browser’s local storage. The CLI stores the token and verdict in your operating system’s user cache with owner-only permissions. License verification sends the token to Sociobot at api.sociobot.in no more than once per day unless you explicitly request a check.

Payments and logs

Sociobot / Dodo is the merchant of record and processes payment details on its hosted checkout. This site never receives card information. Ordinary hosting and API security logs may contain IP address, user agent, path, and timestamp and are retained only as needed for operations and abuse prevention. There are no advertising cookies or behavioral analytics.

Your choices

You can use the free CLI without a license or site storage. Clear this site’s local storage to remove a browser license. Remove apply-witness/license.json from your user cache to remove the CLI cache. For privacy questions, contact privacy@sociobot.in.
